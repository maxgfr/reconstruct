The data model is a single entity defined in `prisma/schema.prisma` (raw copy in
`data/schema/prisma/schema.prisma`). The datasource `db` uses provider
`postgresql` with `url = env("DATABASE_URL")`. There is exactly one model, `User`.

> **Known gap (faithful):** the `User` model is declared but **never queried**. No
> `PrismaClient` is instantiated anywhere, and `GET /api/users` returns a hardcoded
> list rather than rows from this table. The model is captured here for fidelity, but
> nothing in the current source reads or writes it.

## Entities

### User

Postgres table backing the (unused) `User` model.

| Field | Type | Constraints | Relation |
| --- | --- | --- | --- |
| `id` | `String` | Primary key (`@id`); default `cuid()` — a collision-resistant unique id generated by Prisma on create | — |
| `email` | `String` | `@unique` — a unique index enforces one row per email; NOT NULL (no `?`) | — |
| `name` | `String?` | Nullable (optional); no default | — |

- **Primary key:** `id` (`String`, `@default(cuid())`).
- **Unique constraints:** `email` (`@unique`).
- **Indexes:** the `@unique` on `email` implies a unique index; no other `@@index`/`@@unique` is declared.
- **Required (NOT NULL, no default) columns:** `email`. `id` is required but auto-defaulted via `cuid()`. `name` is optional.
- **Foreign keys:** none.
- **Maps to interfaces:** none. No operation in `INTERFACES.md` reads or writes `User` — the entity is currently orphaned from the interface surface.

## Relations & integrity

There are **no relations**: `User` is the only model and it holds no foreign keys,
so there are no 1-1, 1-N, or N-N associations and no cascade rules. There is no
derived or computed data. Referential integrity is limited to the single `@unique`
constraint on `User.email`.

## Enums & domain types

**None.** The schema declares no `enum`, and no field is typed as a status/role/
category set. There are consequently no fixed member lists to enumerate. (If the
User model were ever wired to authentication, a `role` enum would be the natural
first addition — but none exists in the source today, so none is specified.)
